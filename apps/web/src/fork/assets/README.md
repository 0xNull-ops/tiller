# Tiller brand assets

The approved artwork is kept outside this repository. The SVGs are copied directly; `tiller-icon.png`, `tiller.icns`, and `tiller.ico` are the approved
app icon formats. The web favicon and desktop PNG size variants use the supplied compatibility
copies at their original dimensions, renamed here to `tiller-*`.

| Asset in this directory                             | Approved source                            |
| --------------------------------------------------- | ------------------------------------------ |
| `tiller-mark.svg`                                   | `tiller-mark.svg`                          |
| `tiller-mark-light.svg`                             | `tiller-mark-light.svg`                    |
| `tiller-wordmark.svg`                               | `tiller-wordmark.svg`                      |
| `tiller-wordmark-light.svg`                         | `tiller-wordmark-light.svg`                |
| `tiller-app-icon.svg`                               | `tiller-app-icon.svg`                      |
| `tiller-app-icon.png`                               | `tiller-app-icon.png`                      |
| `tiller.icns`                                       | `tiller.icns`                              |
| `tiller.ico`                                        | `icon.ico`                                 |
| `tiller-favicon.ico`                                | `favicon.ico`                              |
| `tiller.iconset/`                                   | `icon.iconset/`                            |
| `tiller-16.png`, `tiller-32.png`                    | `shipyard-16.png`, `shipyard-32.png`       |
| `tiller-48.png`, `tiller-192.png`, `tiller-512.png` | matching `shipyard-*` compatibility copies |
| `tiller-touch.png`                                  | `shipyard-touch.png`                       |

`space-grotesk-medium.woff2` and `space-grotesk-bold.woff2` are the unmodified Space Grotesk
Medium and Bold fonts from [Florian Karsten's repository](https://github.com/floriankarsten/space-grotesk),
commit `03507d024a01282884232081fc6011c09ff4e849`, `fonts/woff2/static/SpaceGrotesk-Medium.woff2`
and `SpaceGrotesk-Bold.woff2`. Their SIL Open Font License is included in `space-grotesk-OFL.txt`.
