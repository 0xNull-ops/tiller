# Contributing

Thanks for wanting to help with Tiller.

## Issues

Bugs, questions and feature requests go to
[Antler-Web-Studios/tiller issues](https://github.com/Antler-Web-Studios/tiller/issues). Include your
Tiller version, OS, the provider you were using and steps to reproduce.

## Pull requests

- One problem per pull request. Small, focused changes get reviewed fastest.
- For a new feature, open an issue first so we can agree on the shape before you build it.
- Follow [AGENTS.md](AGENTS.md): it covers the repo layout, testing rules and the checks to run.
- Run `vp run check:changed` before you push.
- UI changes need before and after screenshots. Motion or timing changes need a short video.
- Use a conventional commit title, such as `fix(web): new threads no longer spike CPU`.

Tiller is maintained in spare time, so reviews may take a few days.

## Security

Please report security issues privately as described in [SECURITY.md](SECURITY.md), not in a public
issue.
